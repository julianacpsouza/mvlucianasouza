Site estático React + Vite para Luciana Souza | Médica Veterinária.

## Deploy gratuito

Use qualquer plataforma de hospedagem estática, como Vercel, Netlify ou Cloudflare Pages.

- Build command: `npm run build`
- Output directory: `dist`
- Node: versão 20 ou superior

O projeto gera um `dist/index.html` padrão e inclui fallback para SPA:

- `vercel.json` para Vercel
- `public/_redirects` para Netlify/Cloudflare Pages
